# Data Folder

Place the dataset file here:

```
data/netflix_titles.csv
```

## Where to get it

Kaggle: https://www.kaggle.com/datasets/shivamb/netflix-shows

Download the CSV and copy it into this folder.

Alternatively, if you have the Kaggle CLI configured (`kaggle` credentials set up),
the notebook can download it automatically via `kagglehub`.

> Note: raw data files are not committed to git (see `.gitignore`).
